# Morning Briefing

The user will paste in tasks or emails from their professor.

1. **Extract tasks** — Read the pasted content and identify all action items assigned to Kai.

2. **Complete tasks** — For each task, complete what you can automatically:
   - Draft email responses
   - Write documentation
   - Run code or build scripts
   - Update files in the project

3. **Generate report** — Output a structured report with four sections:

### To-Do List
A numbered list of every action item found.

### Completed
For each completed item, describe what was done in first person as Kai (e.g. "I drafted a response to Dr. Shi confirming...").

### Email Drafts
Ready-to-send draft for any email replies needed.

### Hours Log
For each completed task:
- Activity name (5 words or less)
- Description (2-3 sentences, first person)
- Estimated time
